# Node.j Quick Introduction:
This folder contains introductory examples covering the following Node.js topics:
- 01-node-program.js
    - Running a Node.js program
    - Entry point, running files, console output, and displaying objects

- 02-process-object.js
    - The Node.js process object
    - process, environment variables, current directory, and Node.js information

- 03-process-event.js
    - Node.js events
    - process.on(), built-in process events, EventEmitter, and custom events

- 04-using-files.js
    - Working with files
    - The two main approaches to reading files: Blocking and Non-blocking

- 05-modules.js
    - Modules in Node.js
    - Using CommonJS and ECMAScript Modules

For more details, please refer to my repository ["Starting with Node.js"](https://github.com/anmarjarjees/node.js-start)
